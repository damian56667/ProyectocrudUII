# 🎨 Skill de Diseño UI - Perfumería

Define la estética Premium de la aplicación.

## Paleta de Colores (Lujo)

- **Primario (Negro)**: `#000000` (AppBar, fondos de botones y textos de títulos).
- **Secundario (Dorado)**: `#D4AF37` (Iconos, bordes decorativos, acentos y botones especiales).
- **Contraste (Blanco)**: `#FFFFFF` (Fondo de la aplicación para limpieza visual).

## Tipografía

- **Fuente**: 'Playfair Display' o 'Serif' para títulos elegantes.
- **Cuerpo**: 'Lato' para lectura clara de precios y stock.

## Componentes UI

- `custom_appbar.dart`: Fondo Negro con detalles y letras en Dorado.
- `perfume_card.dart`: Tarjetas blancas con bordes sutiles en Dorado.
- `luxury_buttons.dart`: Botones Negros con texto en Dorado.
