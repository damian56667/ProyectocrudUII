# 🔄 Skill de Flujo de Trabajo

Procesos operativos para **Nuestras Fragancias**.

## Flujos Principales

1. **Acceso Seguro**: El Admin único ingresa para gestionar la mercancía.
2. **Ingreso de Mercancía**: Inventario -> Formulario -> Registro de costos y stock.
3. **Control de Inventario**: Monitoreo de stock para reposición de fragancias populares.
