# 🎯 Agente Global .agents - Proyecto Perfumería "Nuestras Fragancias"

Este agente coordina el desarrollo de la plataforma de gestión de inventario de lujo para **Nuestras Fragancias**. Se enfoca en la administración de productos exclusivos y control de márgenes de ganancia.

## Estructura del Agente

- `skills/`: Definiciones de arquitectura estética y lógica de negocio.
- `scripts/`: Automatización de tareas técnicas.
- `resources/`: Documentación para la vinculación con Firebase.

## Resumen de Funcionalidad

Esta base está lista para:

1. **Gestión de Catálogo**: CRUD completo para la tabla `perfumes`.
2. **Análisis de Precios**: Control de `precio_compra` y `precio_venta` para cálculo de utilidad.
3. **Seguridad**: Acceso restringido al Administrador para proteger datos comerciales.
